Graph Theory • Breadth-First Search

Word Ladder Puzzle Solver using BFS

A computer science puzzle solver that calculates the minimum number of single-letter transformation steps required to convert a starting word into a target word through a validated dictionary.

Core Algorithm & Strategy
Breadth-First Search (BFS) for state-space traversal
Optimality Guarantee
Guarantees the shortest path in unweighted graph transitions
Data Structures
FIFO State Queue, Hash Set for O(1) dictionary lookup, Visited tracker

Key Engineering Highlights:

  • Level-by-Level Expansion: Enqueues intermediate valid words to systematically inspect nearest neighbors before exploring deeper paths.
  • Cycle Prevention: Maintains an active set of visited words to prevent infinite recursive transitions and redundant evaluations.
  • Path Reconstruction: Stores predecessor references alongside states to retrace and output the complete sequence (e.g., COLD → CORD → CARD → WARD → WARM).
  • BFS Algorithm
  • Graph Traversal
  • Queue ADT
  • Python
  • Complexity Optimization

Machine Learning • Classification

Student Burnout Prediction using Random Forest

A predictive machine learning application designed to assess academic burnout risks among students by analyzing lifestyle habits, study duration, and workload factors.

Model Architecture
Random Forest Classification (Ensemble of Decision Trees)
Core Method
Bootstrap Aggregating (Bagging) with random feature subspace sampling
Technical Stack
Python, Scikit-Learn, Pandas, NumPy, Predictive Analytics

Key Engineering Highlights:

  • Ensemble Robustness: Reduces high variance inherent in individual decision trees by aggregating predictions via majority voting.
  • Multivariate Feature Analysis: Evaluates correlations between daily sleep hours, academic pressure, extracurricular balance, and burnout likelihood.
  • Overfitting Mitigation: Leverages feature randomness at each split to construct uncorrelated estimators and improve generalization on test cohorts.

  • Scikit-Learn
  • Supervised Learning
  • Data Preprocessing
  • Feature Importance
